# Architects and Agents

This repository contains consolidated architecture documentation for all system architects and agents.

## Contents

This repository serves as a centralized location for the following architect documentation:

- **finance-system-architect** - Financial system architecture and documentation
- **support-system-architect** - Support system architecture and documentation
- **sales-system-architect** - Sales system architecture and documentation
- **marketing-system-architect** - Marketing system architecture and documentation

## Purpose

By consolidating these architect repositories into a single location, we:

- Improve discoverability of architecture documentation
- Maintain a single source of truth for system design patterns
- Enable easier cross-system architecture review and collaboration
- Reduce repository sprawl and maintenance overhead

## Organization

Each architect's documentation is maintained in its own subdirectory, preserving the original structure and history from the individual repositories.
